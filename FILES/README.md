# Rexgian Prudente — Portfolio Website

A responsive, dark-futuristic personal portfolio built with plain HTML, CSS, and JavaScript. No frameworks or build tools are required.

## Project files

- `index.html` — page structure and portfolio content
- `style.css` — layout, colors, responsive styling, and animations
- `script.js` — mobile navigation, scroll reveal, and current year

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or use the Live Server extension in Visual Studio Code.

## Customize before publishing

Search the files and replace the sample details:

1. In `index.html`, update the education institution and add your actual study dates.
2. Replace the sample project titles, descriptions, technologies, and GitHub repository links with your real projects.
3. Replace `your-email@example.com` with the email address you want visitors to use.
4. Replace the generic GitHub, LinkedIn, and Facebook profile links with your own profile URLs. Remove any social link you do not want to display.
5. Add a real CV link if you want a downloadable resume section. The current template does not include a resume download because no CV file was supplied.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository**. A convenient repository name is `your-username.github.io` (replace `your-username` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder. Keep the filenames exactly as shown.
3. Open the repository's **Settings**.
4. Select **Pages** from the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then click **Save**.
7. Wait for GitHub Pages to finish publishing. Your site will be available at `https://your-username.github.io/`.

If you use a repository name other than `your-username.github.io`, the URL will usually be `https://your-username.github.io/repository-name/`.

## Notes

- The Google Fonts import requires an internet connection; system fallback fonts will be used if it is unavailable.
- The contact button opens the visitor's email application using a `mailto:` link. It does not submit a form or store messages.
- Review all personal details and public links before publishing.
